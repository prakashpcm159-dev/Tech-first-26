# TECHFEST 2026 🚀

A modern, responsive and accessible official website for **TECHFEST 2026**.

## 📌 Project Overview

TECHFEST 2026 is a multi-page event website that provides information about the event, tickets, venue, sponsors and registration.

The website is designed to be:
- Modern and attractive
- Fully responsive
- Accessible
- Easy to navigate
- Simple to maintain
- Free from JavaScript

## 📄 Website Pages

| Page | Description |
|---|---|
| `home.html` | Main landing page and event overview |
| `about.html` | Information about TECHFEST 2026 |
| `tiket.html` | Ticket and pass information |
| `venu.html` | Event venue and location information |
| `sponsors.html` | Sponsors and partners |
| `register.html` | Accessible event registration form |

## 🛠️ Technologies Used

- HTML5
- CSS3
- Responsive CSS
- Font Awesome
- SVG Images
- Google Fonts
- Google Maps Embed

> **Important:** This project does **not** use JavaScript, `.js` files or `<script>` tags.
